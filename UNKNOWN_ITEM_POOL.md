## 🔐 Exclusivity Mechanisms

### How Items Are Protected

**Database Flag: `pawn_exclusive`**
```python
"velvet_static_wings": {
    "name": "Velvet Static Wings",
    "pawn_exclusive": True,  # ← Prevents inclusion in normal pools
    "zone_ids": [],          # ← Empty = not in zone dives
    ...
}
```

**Exclusion from Dirty Draw:**
- ✅ DIRTY_DRAW_POOL only includes specific item IDs
- ✅ No pawn_exclusive items listed
- ✅ Cannot be pulled from daily draws

**Exclusion from Zone Dives:**
- ✅ `zone_ids: []` (empty) means not findable in zones
- ✅ Check `zone_ids` when generating zone loot
- ✅ Equipment-only exclusion (moonwire_gloves, gloomlace_hoodie)

**Exclusion from Museum:**
- ✅ All secret artifacts have `museum: False`
- ✅ Museum system won't require them
- ✅ Makes them feel even more special

### Implementation in Dive/Draw System

```python
# When generating loot from zones:
if item_data.get("zone_ids") and zone_id in item_data["zone_ids"]:
    # Add to loot
    pass
elif item_data.get("pawn_exclusive"):
    # Skip - pawn-only item
    continue

# When pulling from Dirty Draw:
if item_data.get("pawn_exclusive"):
    # Skip - not included in draw pool
    continue
```

## 🎨 Design Philosophy

### Why These Items Feel Special

**1. Mysterious Naming**
- Not "Iron Gloves" but "Moonwire Gloves"
- Not just "Charm" but "Pawn's Whisper"
- Names hint at stories, not mechanics

**2. Eerie-But-Cute Flavor**
- "Soft to the touch. Buzzes with whispers..."
- "Crown made of forgotten transactions..."
- "Small darkness you can hold..."
- Tone: Unsettling but comforting

**3. Non-Generic Categories**
- Not "weapon" or "armor"
- "Secret artifacts," "ultra-rare equipment"
- Feels like discovering forbidden treasure

**4. Powerful But Niche Effects**
- Not just "+5% coins"
- "Next draw guaranteed" (Pocket Eclipse)
- "+30% next dive bonus" (Midnight Broadcast Tape)
- Effects feel situationally powerful

**5. Story Through Items**
- Glass Eye watches over forgotten
- Soft Engine Heart still beats
- Pocket Eclipse is warm and kind
- Items have personalities

# Display special message
embed.add_field(
